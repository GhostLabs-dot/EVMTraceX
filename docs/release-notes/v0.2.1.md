# EVMTraceX v0.2.1

EVMTraceX is a terminal-first EVM execution trace explorer for developers, auditors, and security researchers. This release ships the renamed `evmtracex` executable and prebuilt binaries for five platform targets.

## Highlights

- Standardize the Cargo package and executable name as `evmtracex`.
- Publish prebuilt binaries for Linux x86-64, Linux ARM64, Windows x86-64, macOS Intel, and macOS Apple Silicon.
- Refresh project documentation and community contribution templates.
- Update Rustls to patched version `0.23.46`.

## Quick start

After downloading, extract the archive and run the binary:

- Linux and macOS: `./evmtracex --help`
- Windows PowerShell: `.\evmtracex.exe --help`

For build-from-source instructions, usage examples, and trace format details, see the [README](https://github.com/GhostLabs-dot/EVMTraceX#readme).
